# Infinite Realities — Android downloads

[Download the latest Android release](https://github.com/SpecterNoir/Infinite-Realities-Releases/releases/latest)

Open the release and download **InfiniteRealities-Godot-Android-BuildNNN.apk**. Install over the existing Infinite Realities Godot app to retain your cards, artwork and decks. Do not uninstall first. Android asks you to confirm installation and may ask you to allow installations from your browser.

Build085 refreshes the mobile home with the new logo, glowing card frames, animated lights and cleaner navigation. Play opens AI setup; challenge other players through Social. Finished matches release the connection automatically. Once-per-turn effects apply to each individual physical card. Tutorial is in More; owner tools are under More > Admin. Update before starting new online matches.

## Updating an installed app

Open **More → App updates**. The app checks for updates outside matches and can download them automatically on unmetered Wi-Fi if enabled. Interrupted downloads can resume. Android still asks you to confirm installation. Finish your match before installing an update.

Both players should use the current version before starting an online match. If a browser download stalls, cancel that download and retry the APK from the release page. Existing players can use **App updates** instead. Keep your installed app and saved data.

## Cards and online play

Published playable cards, artwork and shared layouts sync automatically. Players do not need to pair with Card Studio. Downloaded data remains available offline. Create an Infinite Realities account or sign in while online. After that, AI matches and local decks work offline with your saved sign-in. To play online, open someone’s profile in **Social** and tap **Challenge**. Keep both apps open so the other player can accept and join automatically. A finished match disconnects the players; start another challenge in Social. Help in the app explains reconnecting and includes a support report you can copy when reporting a problem.

These are signed Android playtest releases, not a Google Play or iOS app. The app ID is `com.infiniterealities.godot`. The obsolete Flutter app has a different ID; install Godot separately if migrating from that app. This repository hosts public downloads and service discovery; it does not contain private publisher credentials or Studio project files.
